# Sapien Ventures — parent project hub

This is a single-page, dependency-free local prototype for sapienventures.online. It introduces the parent organization and directs visitors to its independent division websites:

- Sapien Academy: https://sapienacademy.live
- Sapien Consultancy: https://sapienconsultancy.com

All supplied Academy programmes and Consultancy services are listed on the hub, with each project link pointing to its relevant division website. The local server is bound to 127.0.0.1 only.

## Run on Windows

1. Install Node.js 18 or newer. Check with node --version.
2. Open PowerShell in this folder and run:

   cd "$HOME\Documents\SapienVenturesLocal"
   node server.mjs

3. Visit http://127.0.0.1:8000. Press Ctrl+C in PowerShell to stop the server.

The Academy and Consultancy links open their respective sites in a new browser tab. Copy uses warm, plainspoken language and a restrained visual system.
